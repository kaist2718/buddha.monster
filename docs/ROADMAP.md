## 제품 비전

**"마음을 다스리는 하루 10분의 습관"** — 법구경을 읽는 것을 끝이 아니라,
매일의 마음 다스리기 습관으로 확장하는 것을 목표로 한다.

핵심 루프: **오늘의 법구(습관) → 읽기(본문) → 실천(마음 다스리기) → 기록(독송 플랜) → 재방문**

## 기술 로드맵 (상시)

| 항목 | 현재 | 목표 |
| --- | --- | --- |
| 아키텍처 | 정적 사이트 + 빌드 도구(Node 내장 모듈) | 유지 — 프레임워크 도입 없음 |
| 성능 | 서브셋 폰트 1개 + 자체 호스팅 | LCP < 2.5s, 전송량 < 300KB 유지 |

| 측정 | 자체 호스팅 분석(쿠키 X) | 이벤트 측정(오늘의 법구 클릭·암송 모드) |
| QA | verify + browser-check | CI 에 브라우저 점검 추가 |

## 의사결정 원칙

1. **본문 무료 원칙** — 423게송 전문은 어떤 경우에도 무료.
2. **습관 우선** — 신규 기능은 "재방문 습관"에 기여하는가로 판단.
3. **정적 유지** — 서버·DB 없이 운영 가능한 범위에서만 확장.
4. **측정 후 확장** — 가설을 지표로 검증한 뒤 다음 단계 투자.
